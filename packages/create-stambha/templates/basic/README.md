# __PROJECT_NAME__

Stambha bot on the **native stack** — prefix + slash commands, loader, and optional live gateway.

## Quick start (no token)

```bash
pnpm install
pnpm demo
```

## Live bot

```bash
cp .env.example .env
# Set DISCORD_TOKEN and DISCORD_APPLICATION_ID
pnpm start
```
